# Security Policy

## Supported Versions

This project is pre-alpha (0.x); only the latest commit on `main` is
supported. There is no long-term-support branch yet.

## Reporting a Vulnerability

Please report security issues privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
(the "Security" tab on this repository → "Report a vulnerability"), rather
than opening a public issue. Do not include real credentials, tokens, or
other live data in a report.

You should expect an initial response within a few days.
